FarmFlow — גשר שעון נוכחות (ZKTeco / JB Clock)
=================================================

מה זה עושה
----------
קורא את ההחתמות משעון הנוכחות (ZKTeco, פורט 4370) ומקובצי ה-WRK של JB Clock,
מחשב לכל עובד כניסה/יציאה ושעות ליום, ושולח ל-FarmFlow כל 30 דקות.
הקריאה מהשעון אינה הרסנית ולא מפריעה ל-JB Clock.

התקנה (5 דקות)
--------------
1. חלץ את ה-ZIP לתיקייה קבועה, למשל  C:\FarmFlowSync
   (לא לתיקיית הורדות ולא לשולחן העבודה).
2. ודא ש-Python 3.10 ומעלה מותקן:  https://www.python.org/downloads/
   בהתקנה סמן "Add python.exe to PATH".
3. הפעל  install.bat  (לחיצה כפולה). הוא מתקין את החבילות, יוצר משימה
   מתוזמנת כל 30 דקות, ומפעיל את ממשק המגש עם Windows.
4. config.json כבר מכיל את כתובת השרת, מזהה המשק ומפתח ה-API של המשק שלך.
   מה שצריך לבדוק: כתובת ה-IP של השעון ברשת ותיקיית ה-WRK של JB Clock
   (ברירת מחדל C:\jbclock). אפשר לערוך בממשק (אייקון במגש) → "הגדרות".
5. בממשק לחץ "בדוק חיבור" ואז "סנכרן עכשיו". הנוכחות תופיע ב-FarmFlow
   תחת "שעון נוכחות".

קבצים
-----
farmflow_sync.py            הסנכרון עצמו (CLI)
farmflow_sync_ui.py         ממשק גרפי + אייקון מגש
config.json                 ההגדרות שלך (מכיל מפתח API — לא לשתף)
install.bat                 התקנה / התקנה מחדש
uninstall_farmflow_sync.bat הסרה (מבטל משימה ואתחול, לא מוחק קבצים)
run_farmflow_ui.vbs         מפעיל את הממשק בלי חלון שחור
run_sync_hidden.vbs         מריץ סנכרון שקט (למשימה המתוזמנת)

הרצה ידנית
----------
python farmflow_sync.py                 סנכרון החודש הנוכחי
python farmflow_sync.py --month 2026-09 סנכרון חודש מסוים
python farmflow_sync.py --dry-run       חישוב בלבד, בלי שליחה

מפתח API
--------
המפתח בקובץ הזה שייך למשק אחד בלבד. אם הוא דלף, צור מפתח חדש
ב-FarmFlow → הגדרות → שעון נוכחות → "מפתח חדש" והורד חבילה מעודכנת.
